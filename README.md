# 赛博朋克实况转绘 (`cyberpunk-2077-transfer`) v1.0.0

把实拍照片一键转成《赛博朋克2077》游戏截图风格：霓虹夜城、雨夜反射、义体边缘行者、中文霓虹招牌与扫描模式 UI，附可复用的转绘提示词模板。

Transform real-world reference photos into Cyberpunk 2077 in-game screenshot prompts or generated images with maximum CP2077 rendering fidelity. Use when the user provides night city, neon street, night market, bar, night portrait, rainy street, or urban night photos and asks for Cyberpunk 2077 screenshot transfer, photo-to-night-city prompt writing, image-to-image prompts, cyberware and neon signage, or reusable real-photo-to-CP2077 workflows.

## 文件结构

- `SKILL.md` —— skill 定义（含完整转绘提示词配方 / 工作流）
- `agents/openai.yaml` —— agent 配置
- `icon.png` —— skill 定制图标

## 使用方式

将本仓库作为 skill 包使用：把 `SKILL.md`、`agents/`、`icon.png` 放入你的 skill 目录即可。也已同步上架 [skillhub.cn](https://skillhub.cn) 与 ModelScope（魔搭社区），搜 `cyberpunk-2077-transfer` 即可找到。
